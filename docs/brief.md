# Brief

The assignment this project delivers, translated from the original Czech. It is the source of truth for what the page must do: a change that drops one of these requirements is a scope decision for the user, not an implementation detail.

## Goal

A landing page comparing ETFs traded on the NYSE, for a Czech retail investor who arrives from an ad on a mobile phone and gives the page only a few seconds. The page works as a lead magnet: it offers the visitor value and, in exchange, gets their contact. A nice design isn't enough; the page must be optimised for collecting contacts. It also must not look like a default Claude output: design and copy are thought through for this target group. The page is judged mainly on one question: **could we launch an ad campaign on it tomorrow?**

## Requirements

- **Target group.** Define it.
- **The exchange.** Define what the visitor gets in exchange for their contact, and at which moment the page asks for it. The value must be obvious before the visitor fills in the form.
- **Two ad versions.** Design both.
- **First screen.** It follows on from the ad's promise and immediately communicates what the visitor gets.
- **Interactive elements.** The choice is ours (e.g. a fund comparison, a fee calculator, a portfolio builder). Each one leads to the contact form.
- **Form.** As few fields as possible. Design what the visitor receives after submitting it.
- **Data.** Real data, each figure with its source cited.
- **Measurement.** Track the whole journey, from arrival to form submission.
- **README.** Justify the order of the sections, state the expected conversion rate, and list three A/B test hypotheses ranked by expected impact.
- **Deployment.** Deploy the page to free hosting, e.g. Vercel.
